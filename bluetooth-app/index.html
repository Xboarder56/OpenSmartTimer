          Physical reference

          Button & LED guide

          Reset button

          Short press
          While unlocked, enables firmware updates for five minutes.
          Hold 3–5 seconds
          Opens Bluetooth pairing for two minutes. Connect from the app, then short-press Reset to approve it.
          Second short press
          While updates are enabled, permits one unverified firmware upload. Use only with a verified recovery image.
          Hold 10 seconds
          Restores the device name, Wi-Fi, AP, and Bluetooth settings, then restarts. Installed firmware is unchanged.

          Blue status LED

          Solid
          Connected to local Wi-Fi, or standalone AP Mode is ready.
          Fast blink
          Trying to connect to local Wi-Fi.
          Slow blink
          A recovery AP is available.
          Slow single flash
          Bluetooth pairing is open. The pattern changes when an app is waiting for approval.
          Two flashes
          Firmware updates are enabled.
          Three flashes
          One unverified recovery upload is allowed.
          Solid during update
          Firmware is uploading and being validated.
          Rapid update blink
          Firmware was accepted and the timer is restarting.

          Amber lock LED

          On means the lock outputs are energized while a timer is running or paused. Off means the firmware is commanding release; it does not show that the lock opened.

          Emergency input

          An active physical emergency input continuously commands release and prevents a new timer from starting.

          Button gestures are accepted only while the timer is unlocked. Never rely on software as the only release method.
