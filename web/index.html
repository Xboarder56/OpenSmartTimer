Updates are lockedBriefly press Reset on the unlocked timer to allow an update for five minutes.
Unverified firmware allowedThe product marker and known-vendor allowlist will be bypassed for one upload. Header, size, and CRC checks still apply, but they cannot prove the firmware is safe for this hardware.

Online update

Checking does not install anything. Your browser needs Internet access.

Install from a file

Use a firmware .bin you already downloaded.

About firmware updates
Firmware onlyThe vendor filesystem is left untouched. Exact supported original firmware images can also be restored here.
Settings are retainedUpdating this firmware does not erase Wi-Fi, device name, or AP settings. The ten-second factory reset is what clears them.
Use one device for AP updatesFor the most reliable upload, disconnect other phones and tablets from the timer Wi-Fi until it restarts. Other open control pages automatically back off during the update.
Advanced rollback recoveryWhile the normal update window is active, press and release the Reset button again to allow one otherwise-unrecognized application image for this hardware model. A triple blue flash indicates this mode. Use it only when you have verified the image source and hardware layout.

AP security is not API authentication. A WPA2 password protects direct access to the setup AP, but anyone who can reach the timer through your local network can use its controls. Use a trusted or isolated IoT network.

Physical reference

Button & LED guide

Reset button

Short press
While unlocked, enables firmware updates for five minutes.
Hold 3–5 seconds
On V2, opens Bluetooth pairing for two minutes. Connect from the app, then short-press Reset to approve it.
Second short press
While updates are enabled, permits one unverified firmware upload. Use only for a verified recovery image.
Hold 10 seconds
Restores the device name and all Wi-Fi and AP settings, then restarts. Installed firmware is unchanged.

Blue status LED

Solid
Connected to local Wi-Fi, or standalone AP Mode is ready.
Fast blink
Trying to connect to local Wi-Fi.
Slow blink
A recovery AP is available.
Slow single flash
V2 Bluetooth pairing is open. The pattern changes when an app is waiting for approval.
Two flashes
Firmware updates are enabled.
Three flashes
One unverified recovery upload is allowed.
Solid during update
Firmware is uploading and being validated.
Rapid update blink
Firmware was accepted and the timer is restarting.

Amber lock LED

On means the lock outputs are energized while a timer is running or paused. Off means the firmware is commanding release; it does not show that the lock opened.

Emergency input

An active physical emergency input continuously commands release and prevents a new timer from starting.

Button gestures are accepted only while the timer is unlocked. Never rely on software as the only release method.
